# ❤️ Heart Disease Prediction System

**A Machine Learning-Based Application for Heart Disease Prediction**

## 📌 Overview

The **Heart Disease Prediction System** is a Machine Learning project designed to predict the likelihood of heart disease based on user-provided health parameters. It uses a trained **Logistic Regression** classification model to analyze input features and generate predictions.

The project demonstrates the practical implementation of Machine Learning, data preprocessing, feature scaling, model serialization, and model integration into a Python application.

## 🎯 Project Objectives

- Develop a predictive model using the Logistic Regression algorithm.
- Analyze structured health-related data for classification.
- Apply feature scaling and maintain consistent input feature ordering where required.
- Integrate a trained Machine Learning model into a Python application.
- Demonstrate an end-to-end Machine Learning workflow, from data analysis to prediction.

## ✨ Key Features

- **Machine Learning Prediction:** Uses a trained Logistic Regression model.
- **Data-Driven Analysis:** Works with structured heart disease data.
- **Model Persistence:** Loads the trained model using a saved `.pkl` file.
- **Feature Preprocessing:** Includes saved scaler and feature-column information.
- **Reusable Components:** Separates the application, dataset, notebook, and serialized model files.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.9 or a compatible version
- pip package manager
- Required Python libraries
- All required project files, including the saved model and preprocessing objects

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

Navigate to the project directory:

```bash
cd Heart-Disease-Prediction-System
```

Replace the repository URL with your actual GitHub repository URL.

### 2. Install Dependencies

Install the libraries required by your application. A typical setup may use:

```bash
pip install pandas numpy scikit-learn joblib jupyter
```

If your application uses Streamlit, install it as well:

```bash
pip install streamlit
```

### 3. Verify Project Files

Ensure that the following files are available in the expected locations:

- `LogisticRegression_heart.pkl`
- `scaler.pkl`
- `columns.pkl`
- `heart.csv`

The filenames and paths used in `app.py` must match the actual files.

### 4. Run the Application

If `app.py` uses Streamlit, start the application with:

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal to access the application.

If a different framework is used, follow the corresponding execution command.

## 🔄 Project Workflow

1. **Data Collection:** Load the heart disease dataset from `heart.csv`.
2. **Data Analysis:** Explore and prepare the dataset using the notebook.
3. **Model Development:** Train a Logistic Regression classifier using the selected features.
4. **Preprocessing:** Apply the same feature preprocessing used during model training.
5. **Model Serialization:** Save the trained model and associated preprocessing objects.
6. **Prediction:** Load the saved objects and process user inputs through the application.
7. **Output:** Display the prediction generated by the model.

*This workflow describes the intended process; the exact implementation depends on the code in `heart.ipynb` and `app.py`.*
